# Demo Video Script (~3:00)

One continuous story: *shelf → face → routine → verdict → proof → look*.
Record 1080p, screen only (no talking head needed), voiceover in English.
Use the seeded demo account so every screen already has data; the two
"live" moments (4-week preview, steal-a-look) are the only real-time waits
— pre-warm alternates in case Perfect Corp is slow (see prep checklist).

## Editing notes

- Keep the cursor deliberate; pause 1 beat on every AI-filled field so
  viewers register that nothing was typed.
- Scenes 5 & 6 have real 20–40s waits — cut them to ~2s with a speed-up
  and keep the progress bar visible for honesty.
- Subtitles on; judges often watch muted.
- End card text: URL + "sign in → *login as demo user*" + #EveryoneShipsNow.

## Prep checklist (before recording)

- [ ] Demo account seeded: ≥6 products (mixed, ≥1 foundation with shade,
      ≥1 product with empty-OCR box for the fallback moment), 1 scan,
      "everyday" routine active, verdicts generated
- [ ] 4-week preview and steal-a-look **not yet cached** on the take
      account (cached = no live render moment); keep a second scan/look
      ready as backup
- [ ] A makeup-look reference photo saved locally for scene 6
- [ ] Extension loaded unpacked, token pasted, retailer tab + editorial
      tab open
- [ ] Novus dashboard tab logged in with visible traffic
- [ ] Perfect Corp quota checked (< 800 units) — the recording itself
      spends ~15–25 units across takes
- [ ] Record each scene as a separate clip; assemble in edit
